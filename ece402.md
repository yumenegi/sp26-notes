### The Telharmonium 
* **Significance**: Considered the "first purely electronic" synthesizer[cite: 25].
* **Distribution**: Utilized manually switched telephone systems [cite: 21] to play music when lines were free[cite: 22, 23].
* **Technical Limitations**: Signals suffered from crosstalk[cite: 24].
* **Hardware**: Consisted of large equipment with no amplification[cite: 33].
* **Sound Generation**: 
    * Generated by tone wheels driven by motors [cite: 30] using magnetic components[cite: 29].
    * Pickups were used to pick up motion from changing magnetic fields[cite: 32].
* **Timbre Control**: Timbre can be altered [cite: 34, 35] by using multiple pickups[cite: 36].
* **Harmonics**: Harmonics are generated from the same shaft[cite: 37].

### Spectral Analysis
* **Frequency**: The fundamental frequency is determined by the Greatest Common Factor (GCF)[cite: 39].

### Trautonium - Subtractive synthesis
- Start with a "harsh" waveform and remove components

    - The discharging of the neon lamp is not bandlimited
  - Resonant low pass filter

### Hammond Organ
- Laurens Hammond
- Tone wheel organ
- All tone wheels are tuned to equal temperament scale
  - $f=440 \times 2^{(nn-69)/12}$
- 91 tone wheels on the same shaft
- Drawbars control the harmonics
  - Quasi-harmonic frequencies
    - Closest note to the harmonic that works
    - 1:2:2.996:4:5.0397
- Waveform is not periodic
  - Harmonics are not perfect multiples
  - Cannot be sampled

### Analog Modular: Robert Moog
- "East coast studio"
- Modular and changeable controls typically called automation
- Done through analog control voltage
- Two types of control voltage
  - $f=kv$, used for amplitude and stuff
  - $f=f_0 * 2 ^{\frac{v}{v_0}}$, used for pitch and stuff
  - $f_0=\text{reference frequency}$
  - $v_0=\text{volts-per-octave or "Moogs"}$
- Audio and control signal are not differentiated in analog modular
- Control rate vs audio rate in digital domain
- CV is DC-coupled, can be constant voltage
- Audio is AC-coupled, centered at 0
- VCO/VCA/VCF/ADSR

## 02/10/26
### Music Representation
- How to conect music instruments together?
- Purely designed for sequencing and control synthesizers
- Real time MIDI consists of serial connection which transmits events
- MIDI is about 3 ksa/s
  - Faster than the HID of the time
- Tried to replace CV and include audio data
- Super sonic signals can be modulated down to be heard in analog modulars
- Compressed in timing recordings of MIDI stream, MIDI file
- Need precise timing like for drumrolls
- Timestamp, relative delay not absolute to save space in MIDI file
- MIDI as sheet music
  - MIDI has events
  - No key signatures
  - No time signatures
  - Has to guess and imply the data

### MIDI
- Started in 1981
- Attempting to replace CV
- High speed asynchronous serial interface at 31.25 kbaud
- RS-232 standard but electrically different
  - Current loop system, actual current flow between the two connected device
- Ground loop protection
  - Isolated ground
  - Ground loops
  - USB are not isolated
    - Dedicated isolators needed
- Asynchronous serial
- Signal of the serial is sent over MIDI wire
- 31250 kbauds
- LED off when signal is high
  - UART idle is high
- Start bit is transition from high to low
- Stop bit is transition from low to high
  - No data
  - We lose two bits
- Sends LSB first to MSB
- Two different packets, status and data
  - If MSB is 1, status byte
  - If MSB is 0, data byte
  - 3 bits for status code
  - 4 bits for channel number
- 16 channels
- Multi-timbral synthesizer
- MIDI Message
  - Wind instrument
    - Note on event at low pressure to start 
    - Controller change
  - Aftertouch
- MIDI Pitfalls
  - Continuous controller is also sampling
  - If sampling too slow, the control signal would be aliased
  - If modulated by MIDI continuous control that's not bandlimited, the output can be aliased
- MIDI 14-bit
  - The MSB or the LSB are updated first
  - It jumps when rolling over
- General MIDI
  - Multi-timbral
- Active Sense
  - Watchdog timer
- State-based
  - Xinput

### MIDI Extension (MPE)
- Multidimensional polyphonic expression remaps each channel to a voice
- Allows you to have controllers per finger on Continuum

$$cents=100*nn$$
$$f=440*2^{\frac{nn-69}{12}}$$
